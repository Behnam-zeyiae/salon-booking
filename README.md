# سیستم رزرو آرایشگاه برای وردپرس

افزونه‌ای فارسی و سبک برای وردپرس که امکان مدیریت خدمات، ساعات کاری و ثبت آنلاین نوبت مشتریان آرایشگاه را فراهم می‌کند.

> این پروژه در حال توسعه است. پیش از استفاده در محیط عملیاتی، آن را در یک محیط آزمایشی بررسی کنید.

## امکانات

- نمایش فرم رزرو با شورت‌کد `[salon_booking_form]`
- دریافت نام، شماره موبایل، خدمت، تاریخ، ساعت و توضیحات مشتری
- انتخاب تاریخ با تقویم جلالی
- نمایش ساعت‌های کاری و جلوگیری از رزرو زمان‌های پرشده
- مدیریت نوبت‌ها از پنل وردپرس
- تغییر وضعیت نوبت به «در انتظار»، «تأیید شده»، «انجام شده» یا «لغو شده»
- افزودن، ویرایش، حذف و فعال/غیرفعال کردن خدمات
- تنظیم ساعات کاری هر روز هفته
- تنظیم نام، شماره تماس، آدرس و تعداد روزهای قابل رزرو
- ایجاد خودکار جدول‌های موردنیاز و داده‌های پیش‌فرض هنگام فعال‌سازی

## پیش‌نیازها

- وردپرس 5.8 یا بالاتر
- PHP 7.4 یا بالاتر
- دسترسی مدیر وردپرس برای نصب و مدیریت افزونه
- فعال بودن JavaScript در مرورگر کاربران

## نصب

### نصب از پیشخوان وردپرس

1. فایل‌های پروژه را به‌صورت یک فایل ZIP فشرده کنید؛ پوشه اصلی ZIP باید `salon-booking` باشد.
2. در پیشخوان وردپرس به **افزونه‌ها ← افزودن افزونه ← بارگذاری افزونه** بروید.
3. فایل ZIP را انتخاب و نصب کنید، سپس افزونه را فعال کنید.
4. پس از فعال‌سازی، جدول‌های پایگاه داده و داده‌های پیش‌فرض ایجاد می‌شوند.
5. از منوی **رزرو آرایشگاه** خدمات، ساعات کاری و تنظیمات را بررسی و ویرایش کنید.

### نصب دستی

پوشه `salon-booking` را در مسیر `wp-content/plugins/` قرار دهید و افزونه را از بخش **افزونه‌ها** فعال کنید.

## نمایش فرم رزرو

یک برگه جدید بسازید و شورت‌کد زیر را در آن قرار دهید:

```text
[salon_booking_form]
```

سپس برگه را منتشر کنید تا فرم رزرو برای مشتریان نمایش داده شود.

## راه‌اندازی اولیه

پس از فعال‌سازی افزونه:

1. خدمات موردنیاز را در بخش **خدمات** اضافه یا ویرایش کنید.
2. بازه‌های قابل رزرو را در بخش **ساعت‌های کاری** فعال کنید.
3. نام آرایشگاه، شماره تماس، آدرس و محدودیت روزهای رزرو را در **تنظیمات** وارد کنید.
4. یک رزرو آزمایشی ثبت کنید و وضعیت آن را از بخش **نوبت‌ها** بررسی کنید.

## مدیریت افزونه

پس از فعال‌سازی، منوی **رزرو آرایشگاه** در پیشخوان وردپرس در دسترس است و بخش‌های زیر را شامل می‌شود:

- **نوبت‌ها:** مشاهده نوبت‌ها، تغییر وضعیت و حذف نوبت
- **خدمات:** مدیریت عنوان، توضیحات، مدت زمان، قیمت و وضعیت خدمات
- **ساعت‌های کاری:** فعال یا غیرفعال کردن بازه‌های زمانی هر روز
- **تنظیمات:** ویرایش اطلاعات آرایشگاه و تعداد روزهای قابل رزرو

## ساختار پروژه

```text
salon-booking/
├── admin/                    # صفحات مدیریت در پیشخوان وردپرس
├── assets/
│   ├── css/                 # استایل‌های بخش کاربری و مدیریت
│   └── js/                  # اسکریپت‌های بخش کاربری و مدیریت
├── includes/                # کلاس‌های اصلی افزونه
├── templates/               # قالب فرم رزرو
├── salon-booking.php        # فایل اصلی افزونه
└── uninstall.php            # حذف جدول‌ها هنگام حذف افزونه
```

## نکات فنی

- درخواست‌های بخش کاربری از طریق AJAX پردازش می‌شوند.
- اطلاعات رزرو در جدول‌های اختصاصی با پیشوند جدول‌های وردپرس ذخیره می‌شود.
- افزونه برای تقویم جلالی از کتابخانه `jalalidatepicker` استفاده می‌کند که از CDN بارگذاری می‌شود.
- هنگام حذف کامل افزونه، جدول‌های اختصاصی رزرو، خدمات، ساعات کاری و تنظیمات حذف می‌شوند.

## وضعیت فعلی و محدودیت‌ها

- نسخه فعلی: `1.0.0`
- تبدیل تاریخ جلالی به میلادی در منطق فعلی هنوز کامل نشده است؛ بنابراین قبل از استفاده واقعی، صحت تاریخ‌ها را در محیط هدف بررسی کنید.
- برای استفاده عمومی، فعال بودن HTTPS و تهیه نسخه پشتیبان منظم از پایگاه داده توصیه می‌شود.
- قابلیت‌های امنیتی، اعلان پیامکی و پرداخت آنلاین در نسخه فعلی جزو امکانات افزونه نیستند.

## توسعه و مشارکت

برای مشارکت در پروژه:

1. یک Issue برای گزارش خطا یا پیشنهاد قابلیت جدید ایجاد کنید.
2. تغییرات خود را در یک شاخه جداگانه انجام دهید.
3. توضیح مختصر، مراحل بازتولید خطا و اطلاعات محیط وردپرس/PHP را در Pull Request بنویسید.

لطفاً اطلاعات حساس، رمز عبور یا داده واقعی مشتریان را در Issue و Pull Request قرار ندهید.
