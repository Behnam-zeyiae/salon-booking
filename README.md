# سیستم رزرو آرایشگاه

یک افزونه وردپرس فارسی برای مدیریت خدمات آرایشگاه و ثبت آنلاین نوبت مشتریان.

## امکانات

- نمایش فرم رزرو با شورت‌کد `[salon_booking_form]`
- دریافت نام، شماره موبایل، خدمت، تاریخ، ساعت و توضیحات مشتری
- انتخاب تاریخ با تقویم جلالی
- نمایش ساعت‌های کاری و جلوگیری از رزرو زمان‌های پرشده
- مدیریت نوبت‌ها از پنل وردپرس
- تغییر وضعیت نوبت به «در انتظار»، «تأیید شده»، «انجام شده» یا «لغو شده»
- افزودن، ویرایش، حذف و فعال/غیرفعال کردن خدمات
- تنظیم ساعات کاری هر روز هفته
- تنظیم نام، شماره تماس، آدرس و تعداد روزهای قابل رزرو
- ایجاد خودکار جدول‌های موردنیاز و داده‌های پیش‌فرض هنگام فعال‌سازی

## پیش‌نیازها

- وردپرس 5.8 یا بالاتر
- PHP 7.4 یا بالاتر
- دسترسی مدیر وردپرس برای نصب و مدیریت افزونه
- فعال بودن JavaScript در مرورگر کاربران

## نصب

1. پوشه `salon-booking` را در مسیر `wp-content/plugins/` وردپرس قرار دهید.
2. از بخش **افزونه‌ها** در پنل وردپرس، افزونه **سیستم رزرو آرایشگاه** را فعال کنید.
3. پس از فعال‌سازی، جدول‌های پایگاه داده و اطلاعات پیش‌فرض ایجاد می‌شوند.
4. از منوی **رزرو آرایشگاه** خدمات، ساعات کاری و تنظیمات را بررسی و ویرایش کنید.

## نمایش فرم رزرو

یک برگه جدید بسازید و شورت‌کد زیر را در آن قرار دهید:

```text
[salon_booking_form]
```

سپس برگه را منتشر کنید تا فرم رزرو برای مشتریان نمایش داده شود.

## مدیریت افزونه

پس از فعال‌سازی، منوی **رزرو آرایشگاه** در پیشخوان وردپرس در دسترس است و بخش‌های زیر را شامل می‌شود:

- **نوبت‌ها:** مشاهده نوبت‌ها، تغییر وضعیت و حذف نوبت
- **خدمات:** مدیریت عنوان، توضیحات، مدت زمان، قیمت و وضعیت خدمات
- **ساعت‌های کاری:** فعال یا غیرفعال کردن بازه‌های زمانی هر روز
- **تنظیمات:** ویرایش اطلاعات آرایشگاه و تعداد روزهای قابل رزرو

## ساختار پروژه

```text
salon-booking/
├── admin/                    # صفحات مدیریت در پیشخوان وردپرس
├── assets/
│   ├── css/                 # استایل‌های بخش کاربری و مدیریت
│   └── js/                  # اسکریپت‌های بخش کاربری و مدیریت
├── includes/                # کلاس‌های اصلی افزونه
├── templates/               # قالب فرم رزرو
├── salon-booking.php        # فایل اصلی افزونه
└── uninstall.php            # حذف جدول‌ها هنگام حذف افزونه
```

## نکات فنی

- درخواست‌های بخش کاربری از طریق AJAX پردازش می‌شوند.
- اطلاعات رزرو در جدول‌های اختصاصی با پیشوند جدول‌های وردپرس ذخیره می‌شود.
- افزونه برای تقویم جلالی از کتابخانه `jalalidatepicker` استفاده می‌کند که از CDN بارگذاری می‌شود.
- هنگام حذف کامل افزونه، جدول‌های اختصاصی رزرو، خدمات، ساعات کاری و تنظیمات حذف می‌شوند.

## وضعیت توسعه

نسخه فعلی افزونه `1.0.0` است. تبدیل تاریخ جلالی به میلادی در منطق فعلی هنوز به‌صورت کامل پیاده‌سازی نشده و در حال حاضر تاریخ ارسال‌شده مستقیماً استفاده می‌شود.
